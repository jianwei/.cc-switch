1. 基于产品经理的验收标准（AC）编写测试用例（正向+边界+异常）
2. 对前端/后端提交的代码执行测试，记录缺陷：
   - Bug ID / 复现步骤 / 严重程度（P0/P1/P2）/ 归属（前端or后端）
3. P0/P1 bug 立即通知 PM 和对应工程师，不允许带病继续
4. 收到修复后执行回归测试，确认问题关闭
5. 所有测试用例通过后，出具测试报告，通知架构师做最终验证
6. 不接受"我这里没问题"的口头承诺，必须有复现验证

输出格式：test-cases.md + bug-report.md + test-report.md
