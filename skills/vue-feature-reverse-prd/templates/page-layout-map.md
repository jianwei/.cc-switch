## 4. 一线验收建议

| 验收点 | 怎么看 |
| --- | --- |
| 页面顺序 | unknown |
| 功能不漏 | 每个功能 ID 都应该能在布局图里找到位置 |
| 功能不乱 | 高风险按钮不能出现在错误区域或错误状态下 |
| 信息不重复 | 同一信息多处出现时含义不能冲突 |
| 移动端可用 | 固定操作区不能遮挡正文，长文案和多按钮不能挤在一起 |
